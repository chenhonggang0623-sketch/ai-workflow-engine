## 五、今日踩坑记录（避免重复）

1. **`create_all` 不补旧表列**：新增模型列后，已有库必须手动 `ALTER TABLE`（本项目无 alembic 版本管理）
2. **`next.config` 代理端口硬编码 8000**：后端换端口时前端必须同步改，否则页面 500
3. **删除顺序敏感**：外键依赖链必须按叶子→根顺序删，`blueprints.source_execution_id` 是隐藏的第二个引用路径
4. **SQLAlchemy 运算符优先级**：`col == a | col.in_(b)` 会先执行 `a | BinaryExpression` 报错，要用 `or_()` 包裹
5. **prompt 注入占位符**：所有 prompt 用 `.replace()` 而非 `.format()`，用户输入含 `{}` 会炸
