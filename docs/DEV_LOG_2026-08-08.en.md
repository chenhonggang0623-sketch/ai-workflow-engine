## 5. Today's Pitfalls (to avoid repeating)

1. **`create_all` does not add columns to existing tables**: after adding model columns, existing databases must be updated manually with `ALTER TABLE` (this project has no Alembic version management)
2. **`next.config` proxy port hardcoded to 8000**: when the backend changes port, the frontend must be changed in sync, otherwise pages 500
3. **Deletion order matters**: the FK dependency chain must be deleted leaf → root; `blueprints.source_execution_id` is a hidden second reference path
4. **SQLAlchemy operator precedence**: `col == a | col.in_(b)` executes `a | BinaryExpression` first and raises an error, must wrap with `or_()`
5. **Prompt injection placeholder**: use `.replace()` instead of `.format()` for all prompt renderings; user input containing `{}` will break otherwise
