## 五、今日踩坑记录（避免重复）

1. **Provider 输出约定必须是 dict**：`node_runner._run_agent` 会对 `result.output` 做 `output["_executor_metadata"] = ...`，新 provider（如 ensemble）若返回裸字符串会直接 TypeError。新 provider 统一用 `{"output": <str>}` 包裹。
2. **`SUPPORTED_PROVIDERS` 有硬编码断言**：加新 provider 必须同步更新 `tests/test_agent_providers.py::test_supported_provider_names`，否则全量测试红。
3. **`EnsembleProvider` 构造时 self-reference registry**：`register(EnsembleProvider(registry))` 传入的是同一个 registry 实例，候选解析用 `self._registry.get(name)`；注意不要让 ensemble 把自己当作候选（未注册为候选即可，且代码里不嵌套 ensemble）。
4. **前端 provider 切换需清理旧字段**：非 ensemble 切换回单 provider 时，`executor_config.candidates/strategy/mode` 要删除，否则残留配置污染执行。
5. **复用 router 分发、不新建 executor**：ensemble 走 `config.provider == "ensemble"` 的 provider 分发路径即可，无需扩展 `ExecutorType` 枚举，改动面最小。
